Portfolio Project for Intro to Programing Course with Code The Dream
Charles Howe

## Run the portfolio

Open `index.html` in a browser, or use the VS Code Live Server extension to serve the project locally. Select **Dog Information API project** in the Projects section to open the API page.

## Dog Information API

The Dog Information page uses the public Dog CEO API:

- **Show a random dog** sends a GET request to `https://dog.ceo/api/breeds/image/random`.
- **Show dog breeds** sends a GET request to `https://dog.ceo/api/breeds/list/all`.

Each button makes its own request only when clicked. Errors are shown on the page if an API request fails.
